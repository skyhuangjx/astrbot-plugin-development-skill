# 互动会话

读取条件：一次命令需要等待用户后续消息、确认/取消、成语接龙、表单式对话或群组协作。

## 设计

- 使用官方 `session_waiter` 和 `SessionController`，为每个会话设置有限超时。
- 用户输入、退出词、无效输入、超时、异常和取消都要有明确路径。
- 会话中发送消息使用 `await event.send()`；结束时调用 `controller.stop()`，必要时调用 `event.stop_event()`。
- 默认按发送人隔离；群聊协作必须显式定义 `SessionFilter`，并说明群成员是否共享状态。
- 会话状态不可只放一个全局变量；插件重载和禁用时清理等待器、任务和临时数据。
- 涉及真实副作用时，先展示摘要并要求确认，确认消息必须绑定到同一会话和用户。

## 验证

测试并发用户、同一用户多会话、超时后迟到消息、主动退出、插件重载、异常中断和群聊成员边界。

参考：[会话控制](https://docs.astrbot.app/dev/star/guides/session-control.html)。
