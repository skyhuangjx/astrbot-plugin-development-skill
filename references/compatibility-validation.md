# 版本兼容与运行验证

读取条件：插件需要兼容指定 AstrBot 版本，包含 WebUI、后台任务、主动消息、富媒体或外部网络。

## 先锁定真实运行环境

在实现前记录：

- AstrBot 版本和 Python 版本；
- 部署方式和插件安装目录；
- 目标平台适配器及其实例 ID；
- 是否能在目标环境中重载插件并查看日志。

不要只按当前最新版文档判断兼容性。AstrBot 的 WebUI 目录、bridge、元数据和消息适配器在版本间可能变化。若用户给出了版本，优先检查该版本的源码或在该版本运行最小验证。

## 插件导入验证

静态语法检查不能证明 AstrBot 能加载插件。交付前至少验证：

1. 安装包根目录直接包含 `main.py`、元数据和插件包；
2. `main.py` 能以 AstrBot 的插件模块路径导入；
3. 插件内部模块使用相对导入或明确安装的包名，不假设插件目录会自动成为顶层包；
4. `Star` 注册、命令注册、Web API 注册和 `initialize` 均能完成；
5. 缺少可选依赖时，插件能安全停用相关能力并给出可读日志。

例如，插件目录中的 `xmonitor/` 应使用：

```python
from .xmonitor.parser import parse_tweet_response
```

而不是假定任何工作目录下都能使用 `from xmonitor...`。

## WebUI 发现与按钮

WebUI 页面入口和后端 API 是两件事：

- 页面入口由 AstrBot 扫描插件目录中的视图目录并在插件详情页生成入口；
- `context.register_web_api()` 只注册页面调用的后端路由，不会单独生成 WebUI 按钮；
- 目标版本可能推荐 `views/<name>/index.html`，也可能兼容或使用 `pages/<name>/index.html`，必须按目标版本确认；
- `window.AstrBotPluginView` 和兼容别名也要在目标版本中验证。

WebUI 交付验证应按顺序完成：

1. 插件成功加载；
2. 插件详情页出现 WebUI 入口按钮；
3. 页面 iframe 或视图能加载；
4. `bridge.ready()` 返回；
5. `apiGet`/`apiPost` 能访问插件路由；
6. 空请求、非法字段和平台发送失败能在页面显示可读结果。

只打开本地 `index.html`、检查 HTML 语法或看到静态文件存在，都不能证明 WebUI 已接入 AstrBot。

## AstrBot 会话字段

需要用户配置主动推送目标时，页面标签同时显示中文名称和内部字段名：

```text
平台实例 ID（platform_id）
会话类型（message_type）
会话 ID（session_id）
```

字段含义是：

```text
platform_id       平台适配器实例 ID，不是群号
message_type      消息类型枚举值，例如 GroupMessage、FriendMessage
session_id        群号、好友 ID 或平台定义的会话标识
unified_msg_origin 三者组成的完整会话来源，例如 platform_instance:GroupMessage:123456
```

不要把完整 `unified_msg_origin` 填入某个单独字段，也不要把展示名称当作平台实例 ID。

## 运行时阶段和富媒体

涉及外部 API、渲染和主动发送时，日志至少区分：

1. 外部数据查询完成；
2. HTML/图片渲染完成；
3. 适配器发送调用返回；
4. 平台最终送达（如果平台能提供确认）。

每次手动命令、WebUI 测试和后台检查使用独立操作编号，并记录来源、阶段、耗时和文件大小。总耗时不能直接归因于渲染；应分别测量查询、渲染和发送。

平台返回富媒体超时或传输失败时，错误含义通常是“调用方没有及时收到确认”，不一定等于平台最终未送达。没有幂等或去重机制时不要盲目自动重试，否则可能重复发送。应先用同一目标发送小型普通图片，区分平台适配器问题和插件图片大小/格式问题。

远程头像、媒体和字体会让渲染依赖服务器外网。为远程资源设置有限等待时间，并提供首字母或占位图降级；不要让单个外部资源无限期阻塞整张图片。

## 最小验证矩阵

至少覆盖：

- 目标版本的真实插件导入和重载；
- WebUI 入口、bridge、正常 API 和非法 API 请求；
- 命令空参数、`latest` 参数、无结果和 API 超时；
- 监控首次基线、无新推文和有新推文；
- 图片生成成功、远程资源失败降级和空文件；
- 普通文本发送、普通小图片发送和目标平台富媒体失败；
- 后台轮询与手动检查并发时的跳过/忙碌提示；
- 终止和重载时任务、HTTP client、浏览器和临时文件清理。

没有目标 AstrBot 或目标平台时，只能报告语法、模拟或本地验证，不能声称完成了真实 WebUI 或消息发送验证。
